# PR0401: Canalización, objetos y formato en PowerShell

### Bloque 1: Inspección y selección de objetos (`Get-Member` y `Select-Object`)
**1.** Ejecuta el comando que lista los servicios del sistema y canaliza su salida para averiguar qué **tipo de objeto** devuelve exactamente.
```powershell
Get-Service | Get-Member

# El TypeName aparece al principio y tabulado
TypeName: System.ServiceProcess.ServiceController
```

**2.** Lista únicamente las **propiedades** que tienen los objetos devueltos por el comando `Get-Process`.
```powershell
Get-Process | Get-Member -MemberType Properties

# Resultado demasiado largo para ponerlo
```

¿Qué propiedad almacena la ruta del ejecutable o el identificador del proceso (PID)?  
La ruta del ejecutable se almacena en `Path` y el PID se almacena en `Id`.

**3.** Utilizando la sintaxis de paréntesis y el punto `(Comando).Propiedad`, muestra por pantalla únicamente el estado del servicio de Windows Update.
```powershell

```
