# PR0405: Limpieza de logs (II)

## 1. Datos de entrada
Pegamos el siguiente bloque de texto en el script para realizar el ejercicio:
```powershell
$logsWeb = @"
POST /api/v1/auth/login?session=a8f93j2&token=expired [IP: 192.168.10.45] [Agent: Mozilla/5.0] [ERR-0040-AUTH]
GET /api/v2/products/search?q=laptop&sort=asc [IP: 10.0.2.15] [Agent: Chrome/110.0] [ERR-0200-OK]
DELETE /api/v1/admin/drop_table?confirm=true&force=1 [IP: 172.16.254.88] [Agent: ScriptBot/1.2] [ERR-0500-FATAL]
GET /api/v1/user/profile?id=9921&token=xyz [IP: 192.168.10.102] [Agent: Firefox/109.0] [ERR-0403-FORBIDDEN]
"@
```

## 2. Resolución del ejercicio
**1. Extracción y limpieza de la ruta HTTP:** Separar el método HTTP de la ruta de la URL. Eliminar todo lo que hay desde `?` en adelante para quedar únicamente con la ruta limpia. Ejemplo: `/api/v1/auth/login`.  
**2. Enmascaramiento de IP:** Extraer la dirección IP que se encuentra dentro de los corchetes. Por normativas de seguridad, se debe ocultar el último octeto de la IP por asteriscos. Ejemplo: `192.168.10.***`.  
**3. Procesamiento de códigos de error:** Al final de cada línea aparece un código como `[ERR-0040-AUTH]`. Extraer únicamente el número central del error. Ejemplo: `0040`.  
**4. Filtrado de seguridad:** Solo se debe incluir en el informe aquellas peticiones cuyo código de error **no** sea correcto. Solo interesan los errores, bloqueos o fallos.  
**5. Salida estructurada:** Generar objetos **PSCustomObject** con las columnas limpias y exportándolos a un archivo llamado `auditoria_web.csv`.
